# Portal resubmission checklist

## Submit this repository as: Project

Suggested title:

**Weather Parametric Insurance — GenLayer**

Suggested description:

> A decentralized weather parametric insurance application powered by a
> GenLayer Intelligent Contract. Users configure a weather policy, the contract
> enforces a trusted weather-source policy, normalizes and verifies external
> weather data through GenLayer consensus, records evidence on-chain, and moves
> the policy through evaluation, eligibility, settlement, and renewal states.

## Evidence to include

- Working frontend screenshot
- Deployed contract address
- Successful contract deployment screenshot
- Successful weather evaluation transaction / receipt
- Contract state showing `TRIGGERED` or `NOT_TRIGGERED`
- Evidence / weather summary
- Settlement state screenshot if demonstrated

## Category correction

Do not submit this repository under the standalone **Intelligent Contracts**
category. The repository is an application/project because it contains the
user-facing Next.js frontend and supporting integration code.

The standalone contract can be referenced as the project's on-chain backend.
